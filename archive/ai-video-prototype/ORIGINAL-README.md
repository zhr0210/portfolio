```powershell
py -m http.server 4184 --bind 127.0.0.1 --directory site
```

然后打开 `http://127.0.0.1:4184/prototype-directions/ai-video.html`。源码和交互说明在 `site/prototype-directions/`；仅使用浏览器静态服务，无需安装依赖。
