Browser plugin not available；使用 Playwright CLI 驱动 Chromium。桌面为 1440×900，手机视口为 390×844。

已检查：

- 首页矢量字体开场、菜单、观看方式、创作过程、实践档案、作品证据、联系合作。
- 关于我与作品空间切换；全景拖动、归位、键盘进入作品；分类与列表模式。
- 七个作品的资源完整性；详情进入、上一件 / 下一件、Escape 和关闭按钮返回。
- 长图自动阅读、暂停和返回封面控制。一次实测滚动位置从 0 变为 12，暂停后保持 12。
- 联系邀约和能力档案弹窗。复测通过迁移中修复的 React 变量引用。
- 手机首页、菜单、作品浏览、详情和返回；页面没有横向溢出。
- Canvas 兼容渲染、减少动态效果模式、渲染器销毁清理。
- WebGL 上下文丢失后显示七个作品的完整列表；该测试会输出预期的兼容提示 warning。
- 静止时连续采样绘制次数保持不变且 RAF 为 0；离开作品空间停止刷新。模拟 visibilitychange 后暂停，并在恢复时重新绘制。
- `/portfolio/` 子目录部署：主站、图集和详情完整图片正常加载，无 404。

最终相关流程没有页面运行异常或素材加载失败。首次全景在图集准备好后开始完整显现动画，避免网络加载时间吞掉开场效果。

桌面“观看方式”截图与迁移前图像对比，每个颜色通道的平均像素差低于 0.001 / 255；这只证明该稳定画面一致，不代表所有动画帧逐像素一致。首页流动背景随时间变化，未用于固定像素对比。
